# 💰 License Your Private Code to AI Labs — Keep 100% Ownership

Have old **private repositories, internal tools or unreleased side projects** collecting dust? AI labs pay to license real-world code for model training. You keep ownership, and the license is **non-exclusive**, so the same codebase can be licensed and paid for more than once.

## How it works
1. Connect your Git account and get a free per-repo estimate.
2. Approve which repositories you want to offer.
3. Secrets and personal data are stripped from the review copy before anything is shared.
4. You get paid when a buyer licenses your code. In Pangea's words: "Once the buyer's payment is received, you are paid within 15 days to your nominated payout account."

## How earnings work (not guaranteed)
You earn based on how much eligible code you submit – the more you submit, the more you can earn. Earnings depend on buyer demand and aren't guaranteed – see [Pangea's page](https://pangea.ai/code-licensing/companies) for details.

Pangea: "licensing is subject to demand rather than guaranteed, but normally between 2 and 16 weeks."

## ✅ What qualifies
- Code **you own** or have the right to license
- Private repos, internal tools, abandoned startups, side projects

> **My tip (not a Pangea rule):** older, pre-AI-assistant code with full git history is likely the strongest fit; newer repos may get extra questions about how they were built.

## ❌ What does not qualify
- Code that was ever **public** (including an old Internet Archive capture or a published npm/PyPI package), forks, or client-owned code (unless you have the client's written permission)
- Code with confidential data or conflicting third-party rights
- Generated files, vendored/third-party code, binaries, data dumps (don't count toward value)
- WordPress sites, themes and plugins
- AI-written code

> You are responsible for the ownership warranty. Read the full terms before submitting.

## 👥 Who this is for
- Developers with private side projects or abandoned startups
- Startups and companies with old internal tools or legacy services they own
- Software agencies with in-house code they own (not client-owned deliverables)

## ❓ FAQ
**Do I lose ownership?** No. Licenses are non-exclusive; you keep using, modifying and shipping your code.

**Can the same repo be licensed more than once?** Yes, and you are paid each time.

**When am I paid?** Only after a buyer licenses the code; typically 2–16 weeks.

**What about secrets/PII?** They are stripped from the review copy before anything is shared.

**Is income guaranteed?** No. Rates are indicative and depend on buyer demand.
